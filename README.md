# 時間外勤務報告システム

Google Apps Script (GAS) で構築された時間外勤務の報告・集計Webアプリケーションです。

## 📋 概要

社員が時間外勤務時間と振替時間を報告し、所属別・年月別に集計できるシステムです。Google スプレッドシートをデータベースとして使用し、ブラウザからアクセス可能なWebアプリとして動作します。

## ✨ 主な機能

### 1. **ユーザー認証**
- ログインID による認証
- localStorage を使用した自動ログイン機能

### 2. **時間外報告**
- 年月選択による時間外勤務時間の入力
- 振替時間の入力
- 既存データの上書き・新規追加

### 3. **集計機能**
- **所属別集計**: 課・係単位での時間外・振替時間の集計
- **年月別集計**: 月単位での全体集計

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript
- **バックエンド**: Google Apps Script (V8 Runtime)
- **データストレージ**: Google スプレッドシート
- **デプロイ**: GAS Web App
- **開発ツール**: clasp (Google Apps Script CLI)

## 🗄️ スプレッドシート構成

本システムは以下の3つのシートを使用します：

### 1. **ユーザー名シート**
ユーザー情報とその所属を管理

| A列: ログインID | B列: 氏名 | C列: 課 | D列: 係 |
|----------------|----------|--------|--------|
| user01         | 山田太郎 | 営業課 | 第一係 |
| user02         | 佐藤花子 | 総務課 | 庶務係 |

### 2. **テーブルシート**
時間外勤務の記録

| A列: 年月 | B列: ログインID | C列: 時間外 | D列: 振替時間 |
|----------|----------------|------------|--------------|
| 2025年1月 | user01        | 10.5       | 2.0          |
| 2025年2月 | user02        | 8.0        | 1.5          |

### 3. **年月シート**
選択可能な年月のマスタ

| A列: 年月 |
|----------|
| 2025年1月 |
| 2025年2月 |
| 2025年3月 |

## 🚀 セットアップ

### 前提条件

- Google アカウント
- Node.js (v14以上)
- npm
- Git

### 1. リポジトリのクローン

```bash
git clone https://github.com/kotanono0607/zikangai.git
cd zikangai
```

### 2. clasp のインストール

```bash
npm install -g @google/clasp
```

### 3. Google 認証

```bash
clasp login
```

### 4. GAS プロジェクトとの紐付け

#### 既存プロジェクトの場合
`.clasp.json` に既にスクリプトIDが設定されています。

#### 新規プロジェクトの場合
```bash
clasp create --type webapp --title "時間外報告システム"
```

### 5. スプレッドシートの準備

1. Google スプレッドシートを新規作成
2. 上記「スプレッドシート構成」に従ってシートを作成
3. スプレッドシートIDをコピー
4. `Routing.js` の39行目を編集：
   ```javascript
   var ss = SpreadsheetApp.openById("あなたのスプレッドシートID");
   ```

### 6. GAS へのデプロイ

```bash
clasp push
```

### 7. Web アプリとしてデプロイ

1. GASエディタを開く: `clasp open`
2. 「デプロイ」→「新しいデプロイ」
3. 種類: 「ウェブアプリ」
4. アクセス権限を設定
5. 「デプロイ」をクリック
6. 表示されたURLにアクセス

## 🎯 使用方法

### ログイン
1. Webアプリにアクセス
2. ログインID を入力
3. 「ログイン」ボタンをクリック

### 時間外報告
1. メニューから「時間外報告」を選択
2. 年月を選択
3. 時間外・振替時間を入力
4. 送信

### 集計確認
1. メニューから「時間外集計」を選択
2. 「所属別集計」または「年月別集計」を選択
3. 結果を確認

## 🔐 セキュリティ

- 現在の設定では `ANYONE_ANONYMOUS` でアクセス可能です
- 本番環境では適切なアクセス制御を設定してください
- スプレッドシートへのアクセス権限も適切に設定してください
