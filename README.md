# 時間外勤務報告システム

Google Apps Script (GAS) で構築された時間外勤務の報告・集計Webアプリケーションです。

## 📋 概要

社員が時間外勤務時間と振替時間を報告し、所属別・年月別に集計できるシステムです。Google スプレッドシートをデータベースとして使用し、ブラウザからアクセス可能なWebアプリとして動作します。

## ✨ 主な機能

### 1. **ユーザー認証**
- ログインID・パスワードによる認証
- 権限管理（管理者 / 一般ユーザー）
- 退職者のログイン制限
- localStorage を使用した自動ログイン機能

### 2. **時間外報告**
- 年度別アコーディオンUIで年月選択
- 時間外勤務時間・振替時間・備考の入力
- 既存データの上書き・削除
- 編集権限管理（当年度編集可、前年度は4-5月のみ、それ以外は閲覧のみ）

### 3. **ユーザー管理（管理者のみ）**
- 300人規模対応の一覧表示（検索・フィルタ機能）
- 新規ユーザー登録
- ユーザー情報編集（氏名・所属・権限）
- 退職処理（ログイン停止、データ保持）

### 4. **所属変更（全ユーザー）**
- 自分の所属情報を変更可能
- 異動・配置転換時に即座に反映

### 5. **集計機能**
- **所属別集計**: 課・係単位での時間外・振替時間の集計
- **年月別集計**: 月単位での全体集計

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript
- **バックエンド**: Google Apps Script (V8 Runtime)
- **データストレージ**: Google スプレッドシート
- **デプロイ**: GAS Web App
- **開発ツール**: clasp (Google Apps Script CLI)

## 🗄️ スプレッドシート構成

本システムは以下の3つのシートを使用します：

### 1. **ユーザー名シート**
ユーザー情報とその所属を管理（300人規模対応）

| A列: ログインID | B列: 氏名 | C列: 所属１ | D列: 所属２ | E列: 状態 | F列: 権限 | G列: パスワード |
|----------------|----------|------------|------------|----------|----------|---------------|
| admin          | 管理者   | 総務課     | 庶務       | 在職     | 管理者   | admin123      |
| user01         | 山田太郎 | 営業課     | 第一係     | 在職     | 一般     | pass1         |
| user02         | 佐藤花子 | 総務課     | 庶務係     | 退職     | 一般     | pass2         |

**列の説明：**
- **状態**: 在職（ログイン可）/ 退職（ログイン不可、データ保持）
- **権限**: 管理者（全機能アクセス可）/ 一般（時間外報告・所属変更のみ）

**注意**: 初回セットアップ時に管理者ユーザー（admin）を作成する必要があります

### 2. **テーブルシート**
時間外勤務の記録

| A列: 年月 | B列: ログインID | C列: 時間外 | D列: 振替時間 | E列: 備考 |
|----------|----------------|------------|--------------|----------|
| 2025年1月 | user01        | 10.5       | 2.0          | 客先対応 |
| 2025年2月 | user02        | 8.0        | 1.5          | 月末処理 |

### 3. **年月シート**
~~選択可能な年月のマスタ~~ **※廃止（v2.0以降）**

**⚠️ 重要**: v2.0以降、年月リストは自動生成されます。このシートは不要になりました。

システムは自動的に以下を生成します：
- 過去2年度 + 当年度 + 翌年度 = 合計4年度分（48ヶ月）
- 年度基準: 4月〜3月（日本の会計年度）
- 例: 2025年11月時点 → 2023年4月〜2027年3月まで自動生成

## 🚀 セットアップ

### 前提条件

- Google アカウント
- Node.js (v14以上)
- npm
- Git

### 1. リポジトリのクローン

```bash
git clone https://github.com/kotanono0607/zikangai.git
cd zikangai
```

### 2. clasp のインストール

```bash
npm install -g @google/clasp
```

### 3. Google 認証

```bash
clasp login
```

### 4. GAS プロジェクトとの紐付け

#### 既存プロジェクトの場合
`.clasp.json` に既にスクリプトIDが設定されています。

#### 新規プロジェクトの場合
```bash
clasp create --type webapp --title "時間外報告システム"
```

### 5. スプレッドシートの準備

1. Google スプレッドシートを新規作成
2. 上記「スプレッドシート構成」に従ってシートを作成
3. スプレッドシートIDをコピー
4. `Routing.js` の39行目を編集：
   ```javascript
   var ss = SpreadsheetApp.openById("あなたのスプレッドシートID");
   ```

### 6. GAS へのデプロイ

```bash
clasp push
```

### 7. Web アプリとしてデプロイ

1. GASエディタを開く: `clasp open`
2. 「デプロイ」→「新しいデプロイ」
3. 種類: 「ウェブアプリ」
4. アクセス権限を設定
5. 「デプロイ」をクリック
6. 表示されたURLにアクセス

## 🎯 使用方法

### ログイン
1. Webアプリにアクセス
2. ログインID を入力
3. 「ログイン」ボタンをクリック

### 時間外報告
1. メニューから「時間外報告」を選択
2. 年月を選択
3. 時間外・振替時間を入力
4. 送信

### 集計確認
1. メニューから「時間外集計」を選択
2. 「所属別集計」または「年月別集計」を選択
3. 結果を確認

## 🔐 セキュリティ

- 現在の設定では `ANYONE_ANONYMOUS` でアクセス可能です
- 本番環境では適切なアクセス制御を設定してください
- スプレッドシートへのアクセス権限も適切に設定してください
